## 🌟 পরিচিতি (About InfiMart BD)
**InfiMart BD** হলো একটি আধুনিক, দ্রুতগতির এবং সম্পূর্ণ মোবাইল-বান্ধব (100% Mobile-Friendly) ই-কমার্স ও অনলাইন গ্রোসারি প্ল্যাটফর্ম। গ্রাহকরা খুব সহজেই দৈনন্দিন মুদিপণ্য, চাল-ডাল, মাছ-মাংস, মসলা, শাক-সবজি এবং বিশেষ অফার ও প্যাকেজ সরাসরি ওয়েবসাইট এবং হোয়াটসঅ্যাপের মাধ্যমে অর্ডার করতে পারেন।

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. কাস্টমার স্টোরফ্রন্ট (Customer Storefront)
- 📱 **১০০% মোবাইল অপটিমাইজড**: ছোট-বড় সকল স্মার্টফোন ও ট্যাবলেটে স্মুথ স্ক্রলিং এবং রেসপনসিভ লেআউট।
- 🛒 **সহজ অর্ডার ব্যবস্থা**: ক্যাশ অন ডেলিভারি এবং বিকাশ/নগদ/রকেট/ব্যাংকের মাধ্যমে অগ্রিম পেমেন্ট সুবিধা।
- 💬 **সরাসরি হোয়াটসঅ্যাপ ও মেসেঞ্জার অর্ডার**: এক ক্লিকে হোয়াটসঅ্যাপে স্বয়ংক্রিয় মেসেজ পাঠিয়ে অর্ডার কনফার্মেশন।
- 🎁 **প্যাকেজ ও প্রি-বুকিং**: স্পেশাল কম্বো প্যাকেজ ও ক্যাম্পেইন প্রি-বুকিং সিস্টেম।
- ⭐ **রেটিং ও কাস্টমার রিভিউ**: পণ্যের রেটিং এবং রিয়েল-টাইম অ্যাডমিন রিপ্লাইসহ রিভিউ দেখার সুবিধা।

### ২. অ্যাডমিন প্যানেল (Admin Panel)
- 📥 **রিয়েল-টাইম অর্ডার ইনবক্স**: ওয়েবসাইট ও হোয়াটসঅ্যাপের নতুন অর্ডার তাৎক্ষণিক নোটিফিকেশন সাউন্ডসহ ইনবক্সে প্রদর্শন।
- 📊 **দৈনিক ও মাসিক সেলস রিপোর্ট**: Recharts চার্টের মাধ্যমে আয়, ব্যয় ও নিট মুনাফা বিশ্লেষণ।
- 👑 **গ্রাহক লয়ালটি ও ভিআইপি লিডারবোর্ড**: মোট ক্রয় ভলিউমের ভিত্তিতে স্বয়ংক্রিয় লয়ালটি স্কোর এবং স্তর (Platinum, Gold, Silver, Bronze)।
- ⚠️ **স্মার্ট স্টক ও রিস্টক সতর্কতা**: নির্ধারিত থ্রেশহোল্ডের নিচে স্টক নেমে গেলে স্বয়ংক্রিয় হাইলাইট।
- 🚚 **ডেলিভারি চার্জ নিয়ন্ত্রণ**: অ্যাডমিনের ইচ্ছামতো সম্পূর্ণ ফ্রি অথবা নির্দিষ্ট ডেলিভারি চার্জ নির্ধারণের সুবিধা।
- 📥 **এক-ক্লিকে এক্সেল ও সিএসভি এক্সপোর্ট**: অর্ডার, পণ্য, গ্রাহক তালিকা এবং আর্থিক রিপোর্ট ডাউনলোডের সুবিধা।

## 🛠️ প্রযুক্তিগত কাঠামো (Tech Stack)
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4
- **Database & Backend**: Firebase Firestore (Persistent Real-time Cloud Database)
- **Icons & Visuals**: Lucide Icons, Recharts, Canvas Image Processing
- **Exporting**: SheetJS (XLSX)

## ⚙️ লোকাল সেটআপ ও ডিপ্লয়মেন্ট (Setup & Deployment)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/your-username/infimart-bd.git
cd infimart-bd
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. পরিবেশ চলক (Environment Variables) কনফিগার করুন
`.env.example` ফাইলটি কপি করে `.env` তৈরি করুন এবং আপনার ফায়ারবেস তথ্য বসান:
```bash
cp .env.example .env
```
`.env` ফাইলে নিচের তথ্যগুলো প্রদান করুন:
```env
VITE_FIREBASE_API_KEY="AIzaSy..."
VITE_FIREBASE_AUTH_DOMAIN="your-project.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-project-id"
VITE_FIREBASE_STORAGE_BUCKET="your-project.firebasestorage.app"
VITE_FIREBASE_MESSAGING_SENDER_ID="123456789012"
VITE_FIREBASE_APP_ID="1:123456789012:web:abcdef"
VITE_FIREBASE_FIRESTORE_DATABASE_ID="(default)"
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে দেখুন: `http://localhost:3000`

### ৫. প্রোডাকশন বিল্ড তৈরি করুন
```bash
npm run build
```
